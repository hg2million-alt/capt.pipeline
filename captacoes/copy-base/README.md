# Base de copy/persuasão

**A** base de escrita das abordagens. Não existe um modelo de abordagem fixo
de cinco blocos — a escrita parte direto do que está aqui e do gancho do
dossiê de cada prospect.

Fontes atuais: um blog com 10 exemplos reais de WhatsApp e 2 vídeos do
YouTube (um deles transcrito). Ver `INDEX.md` pra consulta por tema — ele é
o ponto de entrada, não ler os arquivos de fonte inteiros a cada abordagem.
Mais material pode chegar depois; cada fonte nova ganha um arquivo próprio
nesta pasta e entra no `INDEX.md`.

**Uso é base, não doutrina.** A técnica se adapta ao seu próprio tom de voz e
ao prospect, não o contrário — nenhuma das fontes deve virar script copiado
literal. Regras que valem acima do banco: gancho é fato verificável levantado
na prospecção, nunca citar outro cliente do mesmo nicho, nada de dado
inventado.
